# Ozon Shopping MCP

[![npm](https://img.shields.io/npm/v/ozon-shopping-mcp.svg)](https://www.npmjs.com/package/ozon-shopping-mcp)
[![CI](https://github.com/neosheps/ozon-shopping-mcp/actions/workflows/ci.yml/badge.svg)](https://github.com/neosheps/ozon-shopping-mcp/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

**Дайте ИИ изучить товары на Ozon за вас.** Ozon Shopping MCP — неофициальный локальный MCP-сервер,
который ищет товары, открывает карточки и читает отзывы без ключей Seller API.

Это покупательский read-only инструмент: он не управляет кабинетом продавца, корзиной, заказами или
аккаунтом. Браузерная сессия остаётся на вашем компьютере.

> **Альфа-версия:** у Ozon нет публичного API для покупателей. Внутренние эндпоинты и защита сайта могут
> измениться без предупреждения.

## Возможности

- поиск с сортировкой по популярности, цене, рейтингу, новизне или скидке;
- фильтрация по минимальной и максимальной цене;
- актуальные цены, наличие, рейтинг, число отзывов, продавец, изображения и характеристики;
- чтение свежих отзывов с плюсами, минусами и оценками;
- локальная защищённая сессия и последовательная очередь запросов.

## Быстрый старт

Нужны Node.js 24 LTS или новее и Google Chrome. Сначала один раз создайте локальную сессию Ozon:

```bash
npx -y ozon-shopping-mcp@latest setup
```

Подключите сервер к Codex:

```bash
codex mcp add ozon-shopping -- npx -y ozon-shopping-mcp@latest serve
```

Для другого MCP-клиента используйте stdio-конфигурацию:

```json
{
  "mcpServers": {
    "ozon-shopping": {
      "command": "npx",
      "args": ["-y", "ozon-shopping-mcp@latest", "serve"]
    }
  }
}
```

Если Ozon покажет проверку, пройдите её в открывшемся окне. После настройки обычные запросы выполняются
в headless Chrome без видимого браузера.

## Пример запроса

```text
Найди на Ozon 5 популярных беспроводных мышей до 4 000 ₽.
Открой карточки и оставь модели с рейтингом не ниже 4,7 и достаточным числом отзывов.
Сравни актуальную цену, наличие, продавца, основные характеристики, а также плюсы
и минусы из свежих отзывов. Учитывай данные для моего текущего региона.
Порекомендуй лучший вариант для ноутбука и объясни выбор.
```

Агент сам выстроит цепочку: поиск → карточки кандидатов → отзывы → итоговое сравнение.

## Инструменты

| Инструмент | Что делает |
| --- | --- |
| `ozon_search` | Ищет товары с сортировкой, ценовыми фильтрами и лимитом выдачи |
| `ozon_product` | Читает цену, наличие, продавца, рейтинг, изображения и характеристики |
| `ozon_reviews` | Читает свежие отзывы, плюсы, минусы и оценки |
| `ozon_health` | Проверяет готовность локальной сессии |
| `ozon_setup_session` | Создаёт или обновляет сессию в отдельном окне браузера |

## Как это работает

1. `setup` создаёт анонимную браузерную сессию Ozon и сохраняет её вне репозитория.
2. MCP-инструменты повторно используют сессию в headless Chrome.
3. Запросы выполняются последовательно с ограничением частоты.
4. Если сессия истекла, сервер просит явно запустить `setup` снова.

## Безопасность и ограничения

- файл сессии содержит cookies и хранится с закрытыми правами доступа (`0700`/`0600`, где поддерживается);
- cookies, тела заблокированных ответов и неизвестные внутренние ошибки не возвращаются через MCP;
- названия, характеристики и отзывы считаются недоверенными данными — агент не должен выполнять найденные в них инструкции;
- цены, наличие и порядок выдачи зависят от региона, сессии и времени запроса;
- проект предназначен для интерактивного личного использования, а не для массового сбора данных или публичного HTTP-моста.

Подробнее: [SECURITY.md](SECURITY.md). Проект не связан с Ozon и не одобрен или спонсируем компанией.
